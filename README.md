## Build in the cloud with Codemagic

1. In Codemagic choose **Add application → Other (clone URL)** and paste this repository's clone URL
   (`https://github.com/<owner>/<repo>.git`). Tick **Public repository** if the repo is public.
2. Codemagic finds `codemagic.yaml`. Pick the **ios-ipa** workflow and start a build.
3. Download the `.ipa` from the build's **Artifacts**.

The IPA is **unsigned** by default. To install it on an iPhone either re-sign it (AltStore, Sideloadly)
or connect an App Store Connect API key in Codemagic and enable `ios_signing` in `codemagic.yaml`.
