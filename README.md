## Build in the cloud with Codemagic

1. In Codemagic choose **Add application → Other (clone URL)** and paste this repository's clone URL
   (`https://github.com/<owner>/<repo>.git`). Tick **Public repository** if the repo is public.
2. Codemagic finds `codemagic.yaml`. Pick the **ios-ipa** workflow and start a build.
3. Download the `.ipa` from the build's **Artifacts**.

## Installable iOS builds

iPhones only install apps signed through Apple. `codemagic.yaml` has three iOS workflows:

| Workflow | Installs on | Needs |
| --- | --- | --- |
| `ios-ipa` | Nothing directly (unsigned; re-sign with AltStore/Sideloadly) | — |
| `ios-adhoc` | iPhones registered in your Apple Developer account, from a link (BetaDrop, Diawi…) | Apple Developer Program |
| `ios-testflight` | **Any iPhone** via TestFlight (public link after Apple's beta review) | Apple Developer Program |

One-time setup for the signed workflows:

1. Join the [Apple Developer Program](https://developer.apple.com/programs/) and create an app record in
   [App Store Connect](https://appstoreconnect.apple.com) with bundle ID **`com.drop2app.bundledpage`**
   (or change the ID in Hacked Drops → App details first — `com.drop2app.*` IDs are just placeholders).
2. App Store Connect → Users and Access → Integrations → **App Store Connect API**: create a key with the
   *App Manager* role and download the `.p8` file.
3. Codemagic → Team settings → **Integrations → Developer Portal**: add the key and name it
   **`codemagic`** (the name `codemagic.yaml` uses).
4. Codemagic → Team settings → **codemagic.yaml settings → Code signing identities**: generate (or upload) an
   *Apple Distribution* certificate, then fetch the **App Store** and **Ad Hoc** profiles for `com.drop2app.bundledpage`.
   For ad hoc, register each tester's iPhone (UDID) under Devices *before* fetching the profile.
5. Start **ios-testflight** (or **ios-adhoc**). TestFlight builds appear in App Store Connect → TestFlight,
   where you add testers or turn on a public link.
